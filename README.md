
# 🟩 Wordle-Inspired Java Game with Hint System

## 📌 Overview
This project is a Wordle-style word guessing game built in Java. Players attempt to guess a hidden word within a limited number of tries. After each guess, feedback is provided to indicate correct letters and positions.

The game also includes a **hint system** to assist players when they get stuck, making it more interactive and beginner-friendly.

---

## ⚙️ Features
- Word guessing gameplay (Wordle-style)  
- Letter-by-letter feedback (correct position, wrong position, not in word)  
- Limited number of attempts  
- Built-in hint system  
- Random word selection  
- Input validation
